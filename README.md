# 本月选股

公开页只放本地操作页最上面的选股：纳指 100 和标普 500 这个月该拿的股票。不含券商账户，不会下单。

页面：https://mikey-si.github.io/stock-good-good-up/

GitHub Actions 在每月 1 日澳门时间 9:00 跑 `update_picks.py`，把页面写进 `docs/` 并推上去。也可以在 Actions 里手动点 Run workflow。

每月这一档会按当时行情重算。选股日仍是每月第 7 个美股交易日收盘；基准收盘跌破 250 日均线时，页面会改成全部持有 TLT。

另外四档是去年涨幅：在 QQQ 或标普 500 里，买上一个完整日历年涨得最多的 1 只（100%）或前 2 只（55% / 45%）。股票必须这一整年都在该指数里，年中才加进来的不算。同一次每月任务会先检查行情里有没有新的年末收盘。没有就保持原来的四档名单。有了上一年最后一个交易日的收盘，才换仓。
